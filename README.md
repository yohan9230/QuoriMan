# QuoriMan

플레이어가 미로 속에서 울타리를 세워 맹수를 따돌리고 출구로 빠져나가는 턴제 미로 탈출 게임입니다.
보드게임 「쿼리도(Quoridor)」의 벽 세우기와 아케이드 게임 「팩맨(Pac-Man)」의 미로 · 점 먹기 · 추격자를 합쳤습니다.

## 하드웨어

- Raspberry Pi 4
- Adafruit 1.3" TFT Bonnet — ST7789 240×240 LCD(SPI), 5방향 조이스틱과 버튼 2개(GPIO)

## 소프트웨어

- Python 3
- Pillow — 화면 그리기
- adafruit-circuitpython-rgb-display — LCD 출력
- Adafruit Blinka · digitalio — GPIO 입력

게임 라이브러리는 쓰지 않습니다. 입력 처리와 그리기는 직접 구현합니다.
